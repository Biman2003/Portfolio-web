## 🛠️ Built With

*   **HTML5** - For the structure and content.
*   **CSS3** - For styling, including responsive design and custom themes (like Dark Mode).
*   **JavaScript (Vanilla)** - For interactive elements like the navigation menu, date/time display, and dark mode toggle.
*   **FontAwesome** - For icons.

## 📂 Project Structure

```
├── index.html       # Main HTML document
├── index.css        # Main stylesheet
├── index.js         # JavaScript file for interactions
├── my img.jpeg      # Profile image
└── README.md        # Project documentation
```

## 🌟 Features

*   **Responsive Design**: The website is fully responsive and works across desktops, tablets, and mobile devices.
*   **Dark/Light Mode**: Includes a toggle to switch between dark and light themes for better user experience.
*   **Smooth Scrolling**: Easy navigation across different sections (Home, About, Skills, Projects, Service, Contact).

## 💻 Getting Started

To get a local copy up and running, follow these simple steps:

1.  **Clone the repository**
    ```bash
    git clone https://github.com/Biman2003/Portfolio.git
    ```
2.  **Open the project folder**
    Navigate to the project directory on your local machine.
3.  **Run the project**
    Simply open the `index.html` file in any web browser to view the portfolio.
